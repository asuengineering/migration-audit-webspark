# Report Families

This document breaks the audit surface into discrete report families.

Each family will eventually receive:

- Drupal source definitions
- WordPress equivalency mappings
- comparison rules
- validation rules
- warning rules
- export schemas

---

## Content

Primary content entities.

Examples:
- nodes
- content types
- publication status
- path aliases
- authorship
- revision state

## Taxonomy

Vocabulary and term structures.

Examples:
- vocabularies
- terms
- hierarchy
- orphaned terms

## Taxonomy Relationships

Connections between content and taxonomy.

Examples:
- node term references
- missing references
- invalid references

## Media

Media entities and references.

Examples:
- images
- documents
- alt text
- captions
- broken references

## Menus

Navigation structures.

Examples:
- menu trees
- invalid links
- unpublished targets

## Users

Authorship and account references.

Examples:
- account status
- role mapping
- missing authors

## Forms

Structured form systems.

Examples:
- Webform
- form elements
- notification configuration
- confirmation behavior

## SEO

Metadata and optimization structures.

Examples:
- meta tags
- canonical URLs
- schema metadata
- redirects

## Warnings

Translation and validation risks.

Examples:
- unsupported component types
- field mapping failures
- missing media
- ambiguous translation states

## Summaries

Aggregate reporting.

Examples:
- content totals
- migration readiness indicators
- unresolved discrepancy counts
